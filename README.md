### 🙋🏻‍♂️ 감상

*Island of Sky*는 Unity를 활용해 처음으로 협업을 경험한 프로젝트였습니다. 개발 기술 자체보다도 역할 분담과 병합 작업의 어려움을 겪으면서 협업의 중요성을 깨닫는 계기가 되었습니다.  
프로젝트 초반에는 비효율적인 작업도 많았지만, 점차 분업 체계를 확립하면서 오히려 개발 속도가 크게 향상되었습니다. 이 경험은 이후의 협업 프로젝트들에서 큰 자산이 되었습니다.
